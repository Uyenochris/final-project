Interactive Story project
Christian Uyeno

Project Concept

My project is a short interactive story where the user types their name and makes choices that change what happens next. Each choice leads to a different ending. The story also shows funny images to make it more entertaining.

Why I Chose This Theme

I chose this theme because I enjoy funny stories and wanted to make something people could interact with. A choose your own adventure story was a simple way to be creative while using JavaScript.

Interactive Features

My project includes:

Text Input – The user types their name and it appears in the story.

Buttons – The user clicks buttons to make choices.

DOM Changes – The text, images, and choices change based on what the user picks.

Events – Buttons and page loading trigger different actions.

Animations – The story text and images fade in smoothly.

Different Endings – Each choice leads to a new part of the story.

Async Operation Used

I used the Fetch API with async/await to load the story from a separate JSON file called story.json.
This file includes all the story text, images, and choices.

Notes for the Grader

All required files are included (HTML, CSS, JS, JSON, and images).

My project uses DOM manipulation, events, user input, JSON data, and async fetch.

The goal was to make a simple but fun story with different paths the user can explore.
